# Getting Started

<p class="lead">
  Tao is a tiny language implemented in Ruby. Three commands are all you need.
</p>

## Install the gem

Taoism is distributed as a Ruby gem and has no dependencies beyond Ruby itself.

```zsh
gem install taoism
```

## Run a script

Write a `.tao` file and run it with `tao`:

```kts
fun main() {
  io.println("hello, world")
}

main()
```

```zsh
tao hello.tao
```

## Open the console

`taoism` starts an IRB-like interactive console for trying snippets.

```zsh
taoism
```

<Callout>
  Running `tao` with no arguments prints a friendly note and exits. Missing
  files and runtime errors are reported on standard error.
</Callout>
